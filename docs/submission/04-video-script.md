# 演示视频脚本

## 灵山胜境 · AI 数字人导览系统

> 时长：≤7 分钟
> 格式：MP4（推荐）
> 建议：全程带旁白解说 + 屏幕操作光标标注

**画面：** 灵山胜境景区全景图/Logo + 系统标题

**旁白：**
"灵山胜境 · AI 数字人导览系统。本系统由我们团队为第十五届中国软件杯 A5 赛题设计开发。系统基于灵山胜境官方数据，打造了覆盖 Web 端、微信小程序和管理后台的三端矩阵，为游客提供 7×24 小时智能导游服务。"

## 场景一：C 端导游 — 智能问答（0:30 - 2:00）

**画面：** 浏览器打开 http://localhost:5173 → 自动进入导游页

**旁白：**
"首先是游客端。打开导游页面，我们看到 AI 数字人形象在右侧展示。左侧是对话面板。"

**操作：**
- 在输入框输入：`"灵山大佛有多高？"` → 回车发送
- 等待返回（显示加载动画 + 数字人口型变化）

**旁白：**
"输入'灵山大佛有多高'，系统通过 RAG 知识库检索，从 ChromaDB 中找到相关知识点，由 DeepSeek 大模型生成回答。可以看到返回了精确数据：通高 88 米、用铜 725 吨等。底部还显示了引用来源。"

**操作：**
- 输入：`"梵宫有什么好看的？"`
- 展示返回结果

**旁白：**
"第二个问题'梵宫有什么好看的'，系统识别出这是文化类问题，返回了梵宫的详细建筑特色和演出信息。数字人同步进行口型动画。"

**操作：**
- 点击语音输入按钮 → 说出"九龙灌浴几点表演？"
- 展示语音识别转文字 → 返回结果

**旁白：**
"支持语音输入。说'九龙灌浴几点表演'，系统自动识别语音、检索知识库、返回演出时间表。整个过程 < 3 秒。"

## 附录：录制注意事项

1. **环境准备**：
   - 启动所有服务：`bash scripts/start-all.sh`
   - 启动前端：`cd frontend && npm run dev`
   - 确保端口 5173/8001/8002/5010 均可访问

2. **分辨率**：建议 1920×1080

3. **录制工具**：OBS Studio / 系统自带录屏均可

4. **光标标注**：建议开启鼠标点击高亮效果

5. **配音**：建议提前准备好旁白录音，后期配合剪辑

6. **字幕**：建议添加中文字幕

7. **每个场景结束时留 1-2 秒过渡**，方便后期剪辑
