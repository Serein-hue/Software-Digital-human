标题：系统架构总览（三端 + 四服务）

架构层级：

## 第8页：核心技术 — RAG 知识库

标题：RAG 检索增强生成管线

检索流程：
```
用户提问 → 意图识别(10类) → Domain过滤 → Embedding(384维) → 
ChromaDB向量检索 → 分数评估 → LLM生成回答 → 返回+引用
```

关键技术参数：
| 项目 | 参数 |
|------|------|
| Embedding 模型 | BAAI/bge-small-zh-v1.5 |
| 向量维度 | 384 维 |
| 向量库 | ChromaDB |
| 知识量 | 73 个文本片段 |
| 检索范围 | 20+ 景点、历史文化、FAQ |
| 分数阈值 | high≥0.65 / medium≥0.45 |

意图识别：10 类（景点事实/门票/时间/路线/亲子/服务/文化/设施/公告/通用）

## 第9页：核心技术 — 大模型集成

标题：多模态大模型驱动

**LLM 大模型：DeepSeek（通过 SiliconFlow API）**
- 场景：RAG 检索后回答生成、多轮对话
- 特点：国产开源，中文能力强，Tokens 成本低

**Embedding 模型：BAAI/bge-small-zh-v1.5**
- 384 维向量，轻量高效
- HuggingFace 镜像下载，离线缓存可用

**语音技术：**
- ASR：Web Speech API（浏览器原生）+ 微信录音 API
- TTS：Edge TTS（浏览器内置）
- 可扩展至：GPT-SoVITS、FunASR、阿里云 NLS

**数字人驱动：Live2D Cubism SDK + 振幅 LipSync**

## 第10页：模型与算法 — LipSync 嘴型同步

标题：自主 LipSync 嘴型同步方案

方案优势：纯软件实现，零 API 成本，低延迟

```
Fay TTS → audio.mp3 → pydub 分帧(50ms) → RMS 振幅归一化 → 
viseme 映射(sil/PP/TH/DD/E/oh/ou/aa) → WebSocket → 
前端 Lipsync.ts → visemeMap → ParamMouthOpenY → Live2D渲染
```

参数：
| 项目 | 值 |
|------|----|
| 帧长 | 50ms |
| viseme 类型 | 8 种 |
| 平滑方式 | 线性插值 |

## 第15页：创新要点

标题：四大创新点

**1. 🧠 意图感知 RAG 检索**
- 10 类游客意图自动识别
- 按意图动态过滤检索 Domain
- 准确率提升 + 响应速度优化

**2. 🗣️ 三级讲解体系**
- 一句话(15s) / 简短(1-2min) / 深度(3-5min)
- 适配不同游览节奏和场景
- 从"抱佛脚多久"到"梵宫建筑故事"全覆盖

**3. 🎭 自研 LipSync 嘴型同步**
- 音频振幅驱动，零 API 成本
- 8 种 viseme 映射，线性平滑过渡
- 无需 GPU，纯 CPU 实时处理

**4. 🏗️ 三端矩阵 + 优雅降级**
- Web / 小程序 / 大屏，一套后端全覆盖
- RAG → Mock → 兜底，三级保障
- 无互联网环境仍可演示核心功能
