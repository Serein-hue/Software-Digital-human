## 视觉规范

- 白底与低饱和深海军蓝、青绿、暖金、柔珊瑚色。
- 核心架构与概念模块使用 GPT Image 科研信息图，并采用准确的中文标签。
- 关键流程、状态机、数据模型和覆盖矩阵使用可编辑 SVG 图。
- 图名保持简短直接，统一采用“总体架构、RAG 流程、口型同步、测试体系”等名称。

## 使用建议

1. 使用支持 SVG 的 Markdown 工具预览或导出 PDF。
2. 展示时优先使用方案设计文档图 1—图 4和创新总结图 1—图 5。
3. 演示视频按“智能问答—数字人播报—路线导览—运营后台”顺序展开。
4. 性能和准确率指标配合测试环境、固定数据集与原始结果展示。
