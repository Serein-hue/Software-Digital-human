- 白底、低饱和深海军蓝/青绿/暖金/柔珊瑚色。
- 精确标签和流程使用 Mermaid，避免 AI 生图中文字失真。
- 概念性生态插图使用 GPT Image，通过 Image Gateway 生成。
- 图注统一说明“概念关系”与“精确实现边界”的区别。

## 使用建议

1. 在支持 Mermaid 的 Markdown 渲染器（GitHub、Typora 等）中预览。
2. 导出 PDF 前确认 Mermaid 已渲染、图片相对路径未失效。
3. 答辩材料中优先使用“创新总结”的图 2—图 5，以及“方案设计”的图 1—图 4。
4. 性能、准确率与覆盖率等硬指标必须附测试环境、固定样本集和原始结果后再使用。
